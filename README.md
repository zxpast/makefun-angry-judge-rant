# Angry Judge: The Short Rant Contest

A deterministic Node 22 program (stdlib only, no network) that writes one
short, funny rant about an everyday annoyance to `/output/entry.txt`.

The rant: the 7:42 bus arrives at 7:58 every single day, and the driver
still waves like they're old friends. The narrator has waved back 214
times — and is not his friend, but a hostage who has learned to smile at
his captor.

## Run

```sh
node main.ts
```

It writes the rant to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Every run produces
byte-identical output.
